# Hotel Dada: the room

A café inside a hotel run by cats. A high window on the back wall shows two real skies,
split by a seam; their light mixes in the room. A cat born from a seed lives there.

One HTML file, no build step, no tracking, nothing stored. The two places come from the
link after the `#`:

    #a=Label,lat,lon,Area/City,mark&b=Label,lat,lon,Area/City,mark     (mark: tower, tree or hills)

Without one, it shows two stand-in cities.
